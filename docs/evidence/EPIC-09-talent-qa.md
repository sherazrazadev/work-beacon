# EPIC-09 — Hire → onboard happy path

1. Sign in (demo account).
2. Header persona → **HR Admin**.
3. Open `/dashboard/recruiting`.
4. Optional: create a job req (title, dept, manager, headcount) — it lists above the board.
5. Open **Jordan Hale** (Offer column) → save scorecard → generate offer (print stub).
6. Click **Hire** (or Hire into onboarding). Jordan moves to Hired; onboarding plan + inbox tasks are created.
7. Persona → **New hire**.
8. `/dashboard/inbox` and `/dashboard/onboarding` show I-9, equipment, training, emergency contact.
9. Mark tasks complete; they persist and stay in sync between inbox and onboarding.
10. Agent as New hire: “What's left in my onboarding?” lists remaining items.
11. Agent: “Suggest a course for TypeScript” → Advanced TypeScript path.
