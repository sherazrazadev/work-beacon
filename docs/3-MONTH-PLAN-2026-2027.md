## 2. Technical Content Model (`src/lib/blog.ts`)

Work Beacon blog articles are typed and statically generated directly into `/blog/[slug]` and `/sitemap.xml`.

```typescript
export type BlogPost = {
  slug: string;                           // Lowercase kebab-case matching target query
  title: string;                          // Authoritative, compelling H1 (max 65 chars recommended)
  summary: string;                        // Meta description & index summary (80-160 chars)
  date: string;                           // ISO date format YYYY-MM-DD
  minutes: number;                        // Estimated reading time (typically 4-8 min)
  topic: "HR" | "Finance" | "IT" | "Agents"; // Strict union topic
  author: string;                         // Approved persona name (see below)
  body: string[];                         // Array of clean, focused paragraphs (typically 4-8)
};
```

### Approved Personas & Topics:
* **Avery Chen** → `HR` (People Operations, Talent Management, Benefits, Compensation Cycles, Succession)
* **Morgan Ellison** → `Finance` (Payroll Operations, Multi-State Withholding, General Ledger, Close Calendar, Headcount Planning)
* **Reese Okonkwo** → `IT` & `Agents` (Workplace AI Safety, Propose-Then-Approve Architectures, Identity & Access Reviews, Learning Ops)

## 3. Brand & Compliance Rules (Mandatory)

1. **Brand Name:** Always **Work Beacon** (never use folder name `workdayforge`).
2. **Brand Voice:** Confident, clean, direct, and authoritative B2B SaaS. Accent `#FF6B35`.
3. **Brand Leak Gate:**
   - **Never include forbidden competitor brand names** (`Workday`, `WorkForge`, or `Sana` as a whole word).
   - Use industry standard terms: *"monolithic enterprise ERPs"*, *"legacy HCM suites"*, *"fragmented point solutions"*.
   - Verify every post with `bash scripts/brand-leak-scan.sh`.
4. **Product Truth:**
   - Emphasize the core value proposition: **"One Record for People, Money, and Systems"**.
   - Emphasize **Propose-then-Approve**: AI agents propose drafts and schedule tasks; humans retain final approval on payroll, compensation changes, and terminations.

    ],
  },
