# Work Beacon design tokens

Enterprise HR / Finance / IT. **Confident + clean** (Stripe / Vercel). Not consumer tool cards. Not Magic UI. Not 3D.

## Type

- Display: Syne
- Body: Manrope
- Scale: 12 / 14 / 16 / 18 / 20 / 24 / 30 / 36 (1.25 ratio)

## Color (60-30-10)

Cooler steel paper — less yellow cream, still not generic SaaS-gray.

- 60% paper `#F3F4F6` + ink `#0C1524`
- 30% surface white + muted `#E8ECF1`
- 10% accent `#FF6B35` — CTAs, current nav, 4px hero bar, focus ring. Do not flood fills or heroes.
- Hero navy `#0B1F3A` (text on navy is white)

## Spacing

8px grid. Dashboard denser (`p-4` / `gap-2`). Marketing spacious (`py-16`–`py-20`).

## Motion

150–300ms ease-out. Honor `prefers-reduced-motion`.
